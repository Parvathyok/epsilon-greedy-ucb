# Bandit Comparison

A local academic project for PARVATHY O K, RA2311026050020, section B. Compare epsilon-greedy and UCB action selection using reproducible simulations.

## Platform
Web interface served locally on macOS; Python numerical backend.

## Users and task
Student and evaluator inspect the completed study, select reward scenarios, run new parameter comparisons, and read the report.

## Stack
Simple server-rendered HTML/CSS and Python/NumPy, chosen as the implementation default. No account, database, API key, or external hosting is required.

## Evidence
The report data consists of generated Bernoulli simulations, not field observations. Preserve all seeds, definitions and uncertainty statements.
