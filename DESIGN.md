# Report-aligned comparison interface

A quiet research workspace using the report’s grayscale visual language. White background, near-black headings, gray rules, readable serif headings, sans-serif controls, and SVG figures with solid/dashed distinctions.

- Background #faf9f6; foreground #191919; secondary #555; border #d8d6cf.
- Content max width 1180px; 32px desktop gutter; 18px mobile gutter.
- Headings Georgia/Times; body system sans; tabular numerals in tables.
- One configuration column beside the primary curve and results table. Stack below 760px.
- Native labelled controls, visible focus outlines, server-side validation, live error text.
- Responsive SVG, horizontal scrolling for data tables only. No decorative animation.
